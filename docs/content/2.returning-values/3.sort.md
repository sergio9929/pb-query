## `.sort(keys)`

[_Since :badge{label="v0.3.0"}_](https://github.com/sergio9929/pb-query/releases/tag/v0.3.0){target="_blank"}

**_Once_** - This can only be used once.

Accepts a single key or an array of keys.

Sorts the results by the specified keys.

Prefixes:
- `-`: Descending order.
- `+`: **DEFAULT**. Ascending order.

Macros:
- `@random`: Orders by [sqlite's random() function](https://sqlite.org/lang_corefunc.html#random){target="_blank"}. Useful for shuffling results.
- `@rowid`: **NOT THE SAME AS `id`**. Orders by [sqlite's internal `rowid`](https://www.sqlite.org/lang_createtable.html#rowid){target="_blank"}. [Can't](https://www.sqlite.org/rowidtable.html){target="_blank"} be used with [View Collections](https://pocketbase.io/docs/collections/#view-collection){target="_blank"}.

```ts
const query = pbQuery<Post>()
  .sort(['title', '-created'])
  .build(pb.filter);

console.log(query.sort) // Output: 'title,-created'
```
