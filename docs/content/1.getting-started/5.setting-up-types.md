To get the most out of `pb-query`, you should define TypeScript types that reflect your PocketBase collections. This allows `pb-query` to provide type safety and autocompletion based on your schema.

## Define Your Types

Create TypeScript interfaces for each of your [PocketBase collections](https://pocketbase.io/docs/collections/){target="_blank"}. Make sure to include all the [fields](https://pocketbase.io/docs/collections/#fields){target="_blank"} you plan to use in your queries.

```ts [types.ts]
export interface User {
  id: string;
  name: string;
  email: string;
  created: Date;
  updated: Date;
}

export interface Post {
  id: string;
  title: string;
  content: string;
  author: User; // relation
  status: 'draft' | 'published';
  created: Date;
  updated: Date;
}
```

## Supported Field Types

| PocketBase Field                                                                                                                                                                                                                                                                                                                                              | TypeScript Type                                           |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------|
| [Plain text](https://pocketbase.io/docs/collections/#textfield){target="_blank"}, [Rich editor](https://pocketbase.io/docs/collections/#editorfield){target="_blank"}, [Email](https://pocketbase.io/docs/collections/#emailfield){target="_blank"}, [URL](https://pocketbase.io/docs/collections/#urlfield){target="_blank"}                                 | `string`                                                  |
| [Number](https://pocketbase.io/docs/collections/#numberfield){target="_blank"}                                                                                                                                                                                                                                                                                | `number`                                                  |
| [Bool](https://pocketbase.io/docs/collections/#boolfield){target="_blank"}                                                                                                                                                                                                                                                                                    | `boolean`                                                 |
| [Datetime](https://pocketbase.io/docs/collections/#datefield){target="_blank"}, [Autodate](https://pocketbase.io/docs/collections/#autodatefield){target="_blank"}                                                                                                                                                                                            | `Date`                                                    |
| [JSON](https://pocketbase.io/docs/collections/#jsonfield){target="_blank"}                                                                                                                                                                                                                                                                                    | `object`, `Array<T>`, or custom type                      |
| [Geo Point](https://pocketbase.io/docs/collections/#geopoint){target="_blank"}                                                                                                                                                                                                                                                                                | Use the `GeoPoint` exposed by `pb-query`                  |
| [Relation](https://pocketbase.io/docs/collections/#relationfield){target="_blank"}                                                                                                                                                                                                                                                                            | Your collection interface ( e.g. `User`)                  |
| Multi-valued Fields ([multiple relation](https://pocketbase.io/docs/collections/#relationfield){target="_blank"}, [multiple select](https://pocketbase.io/docs/collections/#selectfield){target="_blank"}, or [multiple file](https://pocketbase.io/docs/collections/#filefield){target="_blank"})                                                            | Array of the required type ( e.g. `string[]`, `User[]` )  |
| [Select](https://pocketbase.io/docs/collections/#selectfield){target="_blank"}                                                                                                                                                                                                                                                                                | Union of string literals ( e.g. `'draft' \| 'published'`) |

When you use a value of the wrong type in your query, TypeScript will raise an error, helping you catch mistakes early.

```ts
const query = pbQuery<Post>()
  .between('created', new Date('2023-01-01'), new Date('2023-12-31')); // ✅ Correct
```

```ts
const query = pbQuery<Post>()
  .equal('created', '@today'); // ✅ Correct
```

```ts
const query = pbQuery<Post>()
  .equal('created', '2025'); // ❌ TypeScript Error
```

::note
Some field types accept macros and special modifiers, read more about them in [Macros and Modifiers](/getting-started/macros-and-modifiers).
::

## Using Types with pbQuery

When building queries, make sure to specify the type of the collection you are querying.

::code-group
```ts [posts]
const { filter, sort } = pbQuery<Post>() // posts collection
  .search(['title', 'content', 'author.name'], 'footba')
  .and()
  .group((q) =>
    q.equal('status', 'published')
      .or()
      .equal('author.name', 'Sergio')
  )
  .sort(['-created'])
  .build(pb.filter);
```

```ts [users]
const { filter, sort } = pbQuery<User>() // users collection
  .like('name', 'Sergio')
  .build(pb.filter);
```
::

::tip
You can set up query builders for each of your collections, learn how in [Typed Query Builders](/any-problem/tips-and-tricks#typed-query-builders).
::

## Integration with Pocketbase Typegen

If you're already using [Pocketbase Typegen](https://github.com/patmood/pocketbase-typegen){target="_blank"} you can reuse the generated types with `pb-query`. However, they need some adjustments.

[Pocketbase Typegen](https://github.com/patmood/pocketbase-typegen){target="_blank"} produces:

- `RecordIdString` for relations.
- `IsoDateString` for date fields.

These types are `string`-based, so `pb-query` can't infer relations or dates.

### Recommended adjustments

- Replace `RecordIdString` with the actual relation type. This is required, if you don't, you won't get type-checking for nested fields like `author.name`.
- Replace `IsoDateString` with `Date` (optional, but recommended).


::code-group
```ts [Recommended]
import type { PostsRecord, UsersRecord } from './types-from-pocketbase-typegen'

type UsersQuery = Omit<UsersRecord, 'created' | 'updated'> & {
  created: Date;
  updated: Date;
};

type PostsQuery = Omit<PostsRecord, 'author' | 'created' | 'updated'> & {
  author: UsersQuery;
  created: Date;
  updated: Date;
};
```

```ts [Required]
import type { PostsRecord, UsersRecord } from './types-from-pocketbase-typegen'

type UsersQuery = UsersRecord;

type PostsQuery = Omit<PostsRecord, 'author'> & {
  author: UsersQuery;
};
```
::

::note
We recommend using the types ending in `*Record` like `PostsRecord`. However, if you need to access additional fields like `collectionId` inside [`.fields()`](/returning-values/fields), you can use `PostsResponse` instead.
::

## Back-relations

Currently, `pb-query` doesn't have enough context to support [back-relations](https://pocketbase.io/docs/working-with-relations/#back-relations){target="_blank"} properly. It would need to know a lot more about the collection schema, which complicates things quite a bit. We're working on proper back-relation support. Follow [#12](https://github.com/sergio9929/pb-query/issues/12){target="_blank"} for updates.

For now, you can use [back-relation](https://pocketbase.io/docs/working-with-relations/#back-relations){target="_blank"} fields containing `_via_`, but they bypass type-checking:

```ts
const { filter } = pbQuery<User>()
  .like('posts_via_author.name', 'Sergio') // ⚠️ No type-checked
  .build(pb.filter);
```

::warning
Back-relation queries aren't type-safe. Typos like `posts_via_author.titel` won't be caught by TypeScript.
::
