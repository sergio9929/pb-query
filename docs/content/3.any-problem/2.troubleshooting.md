## Common Issues

**Problem:** Date comparisons not working

**Fix:** Always use Date objects:
```ts
pbQuery<Post>().between('created', new Date('2023-01-01'), new Date());
```

## Performance Tips

**Set Max Depth for TypeScript:**
By default, we infer types up to [6 levels deep](https://pocketbase.io/docs/working-with-relations/#expanding-relations:~:text=up%20to%206%2Dlevels%20depth){target="_blank"}. You can change this for each query.

For example, this is 3 levels deep:

```ts
// author.info.age
```

```ts
pbQuery<Post, 3>()
  .equal('author.info.age', 30)
  .and()
  .like('author.email', '%@example.com');
// author.info.age=30 && author.email~'%@example.com'
```
